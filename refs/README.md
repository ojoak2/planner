# Сбор референсов

Веб-приложение, которое по текстовому запросу собирает референсы сразу из
**Pinterest**, **Google Картинок** и **Яндекс Картинок** и показывает их одной
подборкой. За один запрос — **не больше 20 референсов** (лимит задаётся
ползунком от 1 до 20, сервер всё равно режет до 20).

## Запуск

Нужен Node.js 18+. Внешних зависимостей нет.

```bash
cd refs
npm start          # http://127.0.0.1:3000
```

Порт и адрес меняются переменными `PORT` и `HOST`.

## Что умеет

- выбор источников (любая комбинация из трёх);
- результаты источников перемешиваются по очереди, а если какой-то источник
  выдал мало картинок или не ответил, остальные добирают до лимита;
- просмотр в полном размере (стрелки ←/→, Esc), ссылка на исходную страницу;
- скачивание одной картинки или всех/выбранных одним ZIP-архивом
  (в архиве есть `sources.txt` со ссылками на оригиналы);
- копирование ссылок, история последних запросов.

## Как это работает

Браузер не может напрямую ходить на эти сайты (CORS), поэтому поиск делает
локальный сервер (`server.js`):

| Источник | Способ |
| --- | --- |
| Pinterest | внутренний JSON-эндпоинт `BaseSearchResource`, запасной вариант — HTML страницы поиска |
| Google | HTML выдачи `tbm=isch` (из него достаются оригиналы и страницы-источники), запасной — упрощённая выдача `gbv=1` (только превью) |
| Яндекс | JSON из атрибутов `data-state`/`data-bem` страницы поиска, запасной — `format=json` |

`/api/image` проксирует картинки (обход защиты от хотлинка и скачивание),
запросы к локальным/приватным адресам отклоняются.

### Если источник отдаёт капчу

Google и Яндекс иногда блокируют запросы без браузера. Тогда можно поставить
Playwright — сервер сам начнёт использовать headless Chromium как запасной путь:

```bash
npm install playwright
npx playwright install chromium
```

(или указать готовый Chromium через `CHROMIUM_PATH`). Статус каждого
источника и причина ошибки показываются над выдачей.

> Разметка сайтов меняется; если какой-то источник перестал находить
> картинки, правится соответствующий файл в `lib/sources/`.
